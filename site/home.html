Why one balance instead of five subscriptions.

Short version: I got tired of paying five bills.

SaaS got expensive, and every month you pay a surcharge for — what, exactly?

Nobody was doing the obvious thing: buy the good services in bulk, bundle them, sell them at Aldi prices. So I did that. We add a small margin on what the services underneath cost us. That's the whole business model.

No lock-in, because I care whether this is actually good. Unhappy? Take your database and go. Happy? Stay and pay for what you use. And you don't get a dashboard. Ask Codex, Claude, whatever you run — our MCP hands back your usage and your data. No UI. This was built for agents.

Questions about hosting vibe-coded apps.

How do I deploy a Claude Code, Cursor or OpenAI Codex app?

Paste one prompt into your agent. It reads ohmyho.st/llms.txt, creates the project, provisions Postgres, adds your domain and deploys — about two minutes, no Dockerfile, no CLI to install, no dashboard. Works the same in Claude Code, Cursor and OpenAI Codex. Guide for Claude Code.

What is a vibe-coded app, and how do you host one?

A vibe-coded app is one built mostly by prompting an AI coding agent — Claude Code, Cursor, OpenAI Codex, Lovable, Bolt or Replit — rather than by hand. Hosting one means the agent should also deploy it. ohmyho.st exposes hosting, Postgres, email and domains as MCP tools, so the agent that wrote the app can ship it.

How much does it cost to host a Lovable app after export?

From $10 a month on ohmyho.st — 1,000 prepaid credits that cover every project you have, not just the one; busy apps use more, quiet ones almost none. Lovable's own hosting starts at $25 a month per workspace, plus Supabase Pro at $25 per organization once you outgrow the free tier (list prices, September 2026). Lovable export guide.

Can I host my Lovable, Bolt or Replit app after exporting to GitHub?

Yes. Export to GitHub, then paste the prompt. Your agent migrates what usually breaks by hand: Supabase auth redirect URLs, storage buckets, secrets and environment variables for Lovable; env vars, domain and database for Bolt.new; the always-on Postgres setup for Replit. Guides: Lovable, Bolt, Replit.

Is there hosting that isn't priced per project?

Yes — ohmyho.st sells 1,000 prepaid credits for $10, and that one balance works across every project on your account. Five apps or one, no extra base fee per project. Dev and prod environments are included for each project, not billed as two. Quiet projects use close to zero credits.

Is it cheaper than Vercel?

For several small projects, usually yes; for one busy one, not always. Vercel Pro is $20 per seat, Supabase Pro $25 per organization plus about $10 for each extra project, Resend Pro $20 — around $70 for one project and $10 more per additional one. On ohmyho.st an extra project costs only the credits it uses. List prices, September 2026. Full comparison.

Do I need both Vercel and Supabase?

Not if one host gives you both. Vercel hosts the front end and Supabase stores the data; each has its own base fee and neither sends email. ohmyho.st runs hosting, Postgres, transactional email and your linked domain from one balance — one balance for the services you run here, not two subscriptions.

What's a Vercel, Supabase and Resend alternative for small apps?

ohmyho.st covers all three for small apps built with AI agents: hosting instead of Vercel, Postgres instead of Supabase, transactional email instead of Resend, plus a linked domain, AI models and nightly exports — one prepaid balance, from $10 a month. Email is cheaper here at low volume (2,000 emails ≈ $7 from your balance vs a $20 Resend Pro plan) and more expensive at high volume (50,000 emails ≈ $175 vs $20). Is it a Railway or Render alternative?

For small apps, yes. Railway bills usage on idle containers and Render charges $7 per service per month; neither includes email or a domain (September 2026). ohmyho.st bills nothing while a project is idle, and email and domain are in the $10 base price.

Which frameworks can I host?

Next.js, Vite.js, TanStack and React, each with a Postgres database. That's the stack Claude Code, Cursor and OpenAI Codex generate by default, which is why deploys need no Dockerfile. More runtimes later.

Is there a free tier?

Yes: 200 credits, no card. It includes hosting, a Postgres database and a you.ohmyho.st subdomain. Custom domains, email, AI models and backups come with the $10 plan.

Do you have a dashboard?

No. Ask your agent. The MCP server returns your usage, projects and data on request — the same interface the agent used to deploy. There is no web console to learn.

What is llms.txt, and why does the prompt point to it?

llms.txt is a plain-text file a site publishes for AI agents, describing what the site offers and how to use it. ohmyho.st's llms.txt lists every MCP tool for hosting: create project, provision Postgres, set env vars, verify an email sender, add a domain, deploy. The prompt points there so the agent learns the tools without you explaining them.

How does my agent use it?

Through the MCP server. Claude Code, Cursor, OpenAI Codex or any harness that speaks MCP can create a project, provision the database, point the domain and deploy. Each step is a tool call you can read before it runs. No keys pasted between tabs.

What is a spend cap?

A monthly credit ceiling you set yourself. When usage reaches it, ohmyho.st stops the project before it costs more; the site stays up and read-only. A runaway loop or a traffic spike can't turn into a surprise bill.

Can I export my database and leave?

Yes, any time. Your Postgres database is exported nightly as a plain dump to your own Google Drive, Amazon S3 or Cloudflare R2, sent through Zapier, Make, n8n or Composio. Restore it on any Postgres host. No export button to find, nothing to request.
