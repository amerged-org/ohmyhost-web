# Supplied public-site assets

The original home and brand HTML files are supplied by the user and verified by SHA-256 during page preparation. The generated homepage only wires requested links and adds the requested export/automation footer.

Nine logo glyphs are from Simple Icons 16.30.0 (https://github.com/simple-icons/simple-icons), distributed under CC0; their respective brand trademarks remain owned by the brands. Glyph colors match the supplied template palette. Composio uses its first-party https://composio.dev/logos/composio-black.svg asset.

Generated API reference uses the published client OpenAPI contract and Redocly. It does not publish unactivated candidate endpoints.
