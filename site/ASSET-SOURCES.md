# Public-site assets

The supplied v97 home HTML, including explicitly requested section-order changes, is verified by SHA-256 during preparation; the supplied brand HTML retains its own checksum. Generation only wires links, current instructions and the site-requests.js script that copies the agent prompt and drives roadmap voting.

Original logos use Simple Icons 16.30.0 (CC0) and Composio's first-party SVG. Additional Better Auth, Google Drive and Cloudflare/R2 glyphs use the same Simple Icons release; the former Auth0 glyph was removed with the 2026-09-15 auth-support decision. WorkOS and S3 use locally drawn letter/storage substitutes, not claims of official artwork. Respective trademarks remain owned by their brands.

The local og.svg/logo.svg sources are rendered into the checked-in PNG assets with resvg; the page preparation copies those assets without modification. API reference derives from the current public OpenAPI contract. The shared content-page frame derives from the supplied v97 stylesheet.
